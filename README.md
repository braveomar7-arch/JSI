# Jimara Solidarity Initiative (JSI)

Official website for the Jimara Solidarity Initiative, a non-profit, non-political community organisation advancing recognition, mentorship, academic support and civic support in Jimara.

## Publish with GitHub Pages

1. Create a new GitHub repository. A name such as `jsi-website` works well.
2. Upload every file and folder in this package to the repository.
3. Make sure the default branch is named `main`.
4. Open **Settings → Pages** in the GitHub repository.
5. Under **Build and deployment**, choose **GitHub Actions** as the source.
6. Open the **Actions** tab. The “Deploy JSI website to GitHub Pages” workflow will publish the site automatically.

After a successful deployment, GitHub shows the website URL in **Settings → Pages**. Future pushes to `main` automatically republish the site.

## Edit the website

- Page content: `dist/index.html`
- Colours and design: `dist/styles.css`
- Menu and scroll effects: `dist/script.js`
- Community photographs: `dist/assets/`

The co-founder cards currently use initials as replaceable portrait placeholders. When real portrait photographs are ready, add them to `dist/assets/` and update the corresponding cards in `dist/index.html`.

## Local preview

Open `dist/index.html` in a web browser. For best results, serve the `dist` folder with any simple local web server.
